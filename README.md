# Classic Match Archive

A responsive League of Legends Classic match tracker generated from `League_of_Legends_Classic_Match_Tracker.xlsx`.

## Features

- Dashboard with archive-wide match statistics
- Player profiles and champion performance
- Searchable, expandable match history
- Guided match and performance entry
- Device-local additions with JSON export
- Automatic GitHub Pages deployment

## Local development

```bash
pnpm install
pnpm exec next dev
```

## GitHub Pages

Push the `main` branch to GitHub, then enable **Settings → Pages → GitHub Actions**. The included workflow builds and deploys the site automatically.
